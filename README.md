## Beschreibung

Raisonix produziert, verwaltet und vertreibt in unterschiedlichen Divisionen eigene Dienstleistungen, Projekte, Publikationen und weitere Produktionen. Über "RR Utilities" (auf GitHub) wird die technische Infrastruktur gehostet.
